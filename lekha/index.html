Lekha

Free, open-source accounting software for Indian businesses, for Windows. Version 1.2.0

Keep your books on your own computer: sales and purchase invoices with GST, quotations, payments, credit and debit notes, stock, and reports. No account, no subscription, and no internet connection needed to work.

What it does

  • GST invoices, with GSTR-1, GSTR-2 and GSTR-3B summaries prepared from them to help you file. Check them with your tax professional before filing.
  • Profit and loss, balance sheet, trial balance and general ledger.
  • Stock, purchase receipts and shipments (turn on Inventory in Settings).
  • Import from Tally: groups, ledgers, customers and suppliers, stock items, opening balances and vouchers, from an XML export of Tally ERP 9 or TallyPrime. Vouchers come in as journal entries, so imported sales and purchase vouchers do not appear in the GST reports.

How to install

With the installer

  1. Download the installer and check its checksum (below).
  2. Double-click it. If SmartScreen appears, choose More info, then Run anyway.
  3. Follow the wizard, then start Lekha from the Start menu. Create a new company, or try the demo company first.

To remove it: Settings ▸ Apps ▸ Installed apps ▸ Lekha ▸ Uninstall. Your company files are kept.

Using version 1.0.0? It does not check for updates, so install 1.2.0 over it once; your data is kept. Later versions arrive automatically.

With the portable version

  1. Save the file in a folder you own, such as C:\Tools\Lekha.
  2. Run it. If SmartScreen appears, choose More info, then Run anyway.

Moving from Tally

  1. In Tally, export your masters (List of Accounts) and your vouchers (Day Book) in XML format.
  2. In Lekha, open Setup ▸ Import from Tally, select the masters file first, then the vouchers file, and choose Import Data.
  3. Compare the trial balance with Tally before you continue working.

Your data

Your company file is saved on your computer, where you choose. Lekha uses the internet only to check GitHub for a new version, to download a language other than English if you pick one, and to sync with your own ERPNext server if you set that up.

Check your download

In PowerShell, in the folder you downloaded to:

Get-FileHash .\Lekha-Setup-v1.2.0-windows-x64.exe -Algorithm SHA256

The result must match the SHA-256 below. If it doesn't, delete the file and download it again.
