Livi Pen

A free, open-source vector illustration app. Version 0.16.0 (alpha)

Draw and edit paths with the pen, pencil and shape tools, combine shapes with Pathfinder, style them with fills, strokes, gradients and effects, set type, and lay out artboards. Livi Pen opens and saves SVG, PDF and EPS, exports PNG and more, and prints. It runs on your computer and does not upload your files.

Livi Pen is in alpha: the main workflows work from start to finish, but expect rough edges.

Try it in your browser

No download, no installation

The full app runs in your browser. Your drawings stay on your computer: open and save files with the File menu. It works best on a desktop or laptop in a recent Chrome, Edge, Firefox or Safari. The first start downloads about 30 MB, so give it a moment.

How to install

Windows

  1. Download the .msi file and double-click it.
  2. If SmartScreen says "Windows protected your PC", choose More info, then Run anyway. Answer Yes to the administrator prompt.
  3. Follow the wizard, then start Livi Pen from the Start menu.

To remove it: Settings ▸ Apps ▸ Installed apps ▸ Livi Pen ▸ Uninstall. With the portable zip, extract it to a folder you own (not inside the zip), run livipen.exe, and delete the folder to remove it.

macOS

  1. Open the .dmg and drag Livi Pen onto Applications.
  2. Open Livi Pen from Applications. macOS says it can't check the app; close that message.
  3. Go to System Settings ▸ Privacy & Security, scroll down and choose Open Anyway next to the Livi Pen message, then confirm. You only do this once.

Linux

chmod +x livipen-0.16.0-linux-x86_64.AppImage
./livipen-0.16.0-linux-x86_64.AppImage

Or install a package: sudo apt install ./livipen-0.16.0-linux-x86_64.deb, sudo dnf install ./livipen-0.16.0-linux-x86_64.rpm, or flatpak install --user livipen-0.16.0-linux-x86_64.flatpak.

Check your download

On Windows, in PowerShell, in the folder you downloaded to:

Get-FileHash .\livipen-0.16.0-windows-x64.msi -Algorithm SHA256

On macOS or Linux: shasum -a 256 FILE. The result must match the SHA-256 below. If it doesn't, delete the file and download it again.
