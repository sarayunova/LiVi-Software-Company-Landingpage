PageForge

A free, open-source PDF app for Windows. Version 0.13.0

Read, annotate, fill in, sign, organize, compare and redact PDFs, with text recognition (OCR) for scanned pages. Your documents stay on your computer: PageForge does not upload them. The only network use is the optional Help ▸ Check for updates command, which asks GitHub for the latest release when you choose it.

How to install

With the installer

  1. Download the .msi file and check its checksum (below).
  2. Double-click it. If SmartScreen appears, choose More info, then Run anyway. Answer Yes to the administrator prompt.
  3. Follow the wizard, then start PageForge from the Start menu.
  4. To make it your default PDF app: Settings ▸ Apps ▸ Default apps. The installer never changes your default by itself.

To remove it: Settings ▸ Apps ▸ Installed apps ▸ PageForge ▸ Uninstall.

With the portable zip

  1. Right-click the zip, choose Extract All…, and pick a folder you own, such as C:\Tools\PageForge. Don't run it from inside the zip.
  2. If the program won't start, right-click the zip before extracting, open Properties, tick Unblock, press OK, and extract again.
  3. Run pageforge.exe. To remove it, delete the folder.

Check your download

In PowerShell, in the folder you downloaded to:

Get-FileHash .\pdfcraft-0.13.0-windows-x64.msi -Algorithm SHA256

The result must match the SHA-256 below. If it doesn't, delete the file and download it again.
